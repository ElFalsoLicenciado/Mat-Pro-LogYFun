# Solucionador de laberintos

## **Fecha**: 09/01/26

## **Descripción**: 
Crear un programa que permita resolver cualquier laberinto usando recursividad para desplazarse.

## Descripción del código

### Clase `Methods`

Las variables de la clase son:
- *maze*: Matriz del layout del laberinto.
- *MAX_X* y *MAX_Y*: Longitud de la matriz en X y  Y.
- *endX* y *endY*: Coordenadas de la meta.
- *posX* y *posY*: Coordenadas de la posición.
